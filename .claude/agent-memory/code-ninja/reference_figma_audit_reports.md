**These sections use a DIFFERENT kit from COURSES/DOCUMENT HUB** ([[reference-figma-courses-section]]).
Do not mix them:

- card `rounded-[12px] border border-[#e2e8f0] shadow-[0px_1px_2px_0px_rgba(0,0,0,0.05)] overflow-hidden`
- card header `border-b border-[#f1f5f9] px-6 pt-6 pb-[25px]`, title `text-[18px] font-bold text-[#0f172a]`
- table head **uppercase** `h-12 bg-[#f8fafc] px-6 py-4 text-[12px] font-bold tracking-[0.6px] text-[#64748b]`
- body cell `h-[71px] px-6 py-4 text-[14px] text-[#0f172a]`; date column `#64748b`
- search `h-10 w-[300px] rounded-[8px] bg-[#f8fafc]` **borderless**; outline button `h-[38px] rounded-[8px] border-[#e2e8f0] px-[13px] text-[14px]`
- stat card 340×166, `p-6`, 36px `rounded-[8px] bg-[#f8fafc]` icon box, 12px info glyph at top-6/right-6, label `text-[14px] text-[#64748b]`, value `text-[28px] font-bold`
- 3-up stat grid `gap-6` totalling 1068; content column `gap-[40px]`

These are encoded in `src/components/dashboard/auditor/audit-ui.ts` — reuse those constants.

**Design intent the app cannot satisfy without new logic** (all still open): tabs live in the
top NavBar row; every table has a pagination footer; the Overview card has a search field; Staff
has a Department/Role column; Export History has Generated By / Generated At columns and a
Cancel Export action.

**Figma's own slips:** "Audit Reportss" and "All Staffs" typos; the Staff frame draws 65px rows
with `#f8fafc` separators while Courses/Overview draw 71px rows with none.
